# IntegratedChinese-Anki
This deck is designed to test chapter vocab from the Integrated Chinese textbook (vol. 4). All 3 levels are included. 
The instructions provided below assume no prior familiarity with Anki.
 
Anki has quite a few advantages over traditional flashcards. It is portable (you can even put it on your phone with the AnkiDroid app), it has interactive cards (multiple choice, drawing, spoken audio, etc.), and it keeps track of your progress to dynamically quiz you every day, making sure to show your personally less well-known words more often and the better-known ones less often.
It is free and open source. But, it is also free and open source. Thus it has a steep learning curve. Unless you download this repository, which has the settings already well-aligned!

Terms:
Deck = A group/subgroup of flashcards. Decks are organised so you may select any individual lesson, an entire level, or the whole repository to study from at once.
Note = A single 'note' corresponds to a single word/phrase and its raw data.
Card/Card Type = A 'card type' in Anki is the style of flashcard, independent from any vocab entry. In this deck there are 4 card types: Multiple Choice, Standard, Tone selection, and Hanzi Drawing Practice. For each note there are all four card types, so although there are 92 cards in Lesson 1 Deck, there are only 23 notes. (notes per deck*card types=cards per deck).

This is why the daily new card learning limit is set to around 16-28; although this sounds like too many new words to learn in a day, one really only learns the amount of words that are a quarter of the new cards quantity (4-7 new words or 'notes' a day.) The individual per-lesson deck new card limits vary from 16-28, customized to fit each lesson within a 7-day period (but this is only done for IC Level 1, you must manually set for the other 2 levels once you reach them based on the formula defined above).

----- HOW TO IMPORT THE .colpkg INTO ANKI -----
1. Download Anki on a computer and create an account, where your flashcards and progress will be backed up (and synced to your phone if you want to use that.)
2. Once open, go to File>Import>'IC Level 1-3 Vocab Anki Flashcards.colpkg'. Select 'Yes' on the popup (unless you have any decks already in Anki. then back those up as File>Export>.apkg first.) 

----- WHEN LEARNING A LESSON DECK -----
1. Go to 'Decks' tab in the top taskbar. Select the desired deck (usually I do it lesson-by lesson instead of selecting the overarching level, so that each lesson can be perfectly paced with the new card limit.)
2. When flipping through flashcards, mostly select 'Again' or 'Good' to grade yourself. The other options may be used but they confuse the built-in pacing algorithm.

----- WHEN PREPARING TO START REVIEWING A FINISHED DECK -----
1. Go to the 'Decks' tab, select the gear icon next to the learned deck to enter the deck settings menu.
2. Click the top dropdown and change from 'Default' to 'Learned'. This switches the flashcard style from constant re-drilling of words to a less repetition-heavy setting.
